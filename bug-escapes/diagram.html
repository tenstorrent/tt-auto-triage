Detection Pipeline — 4 Phases

1

Discovery & Mapping

  • Hardcoded workflow list from aggregate-workflow-data.yaml
  • Classify each as pr-gate, merge-gate, or other
  • Fetch each "other" workflow YAML via gh api
  • Cursor Agent classifies which layer each workflow tests
→ pipeline-config.json
2

Candidate Failures

  • Fetch runs from last ~2 weeks per workflow
  • Group jobs by name, find 3+ consecutive failures
  • Download failure logs for each candidate
  • Cursor Agent verifies: deterministic bug vs. infra noise
→ consistent-failures.json
3

Find Fix Points

  • Walk forward from each failure to find first passing run
  • Skip failures still active (no fix yet)
  • List commits between fail→pass transition
  • Cursor Agent attributes fix to specific commit & layer
→ fix-points.json
4

Classify & Output

  • Compare fix commit layer vs. test layer
  • Same layer → horizontal escape
  • Lower layer → vertical escape
  • Write GitHub Actions step summary
→ bug-escapes-output.json

Bug Escape Types

Horizontal Escape

A test in an "other" pipeline for layer L was failing consistently. The fix commit changed code in the same layer L.

PR-gate or merge-gate for that layer should have caught it.

test layer: ttnn  │  fix layer: ttnn
→ same layer = horizontal escape

Vertical Escape

A test for layer L was failing consistently. The fix commit changed code in a lower layer than L.

The lower layer's own tests should have caught it.

test layer: ttnn  │  fix layer: tt-metalium
→ fix in lower layer = vertical escape

Tooling & Key Constraints

🔧

gh CLI

All GitHub API data fetching — workflow runs, jobs, logs, commits. Authenticated via GITHUB_READ_TOKEN.

🤖

Cursor CLI Agent

All analytical judgment calls — failure determinism, fix attribution, layer classification. Headless -p mode, JSON output.

📦

Reused auto-triage libs

github_api.sh, config.sh, common.sh, list_commits_between.sh, get_changed_files.sh

⚖️

Key Rule

Scripts fetch data. Agents make decisions. No regex log parsing — every judgment is agent-driven.
